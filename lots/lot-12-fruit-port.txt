# ⚠ ONZE DE CES ESPÈCES COMPLÈTENT DES GROUPES DE CONFUSION encore à moitié illustrés.
# C'est le critère qui a le mieux servi depuis le lot 1, et il reste du travail :
#   - AIL DES OURS, dans « Ail des ours & sosies de printemps » avec le muguet MORTEL,
#     l'arum et le colchique. Son fruit (capsule à trois loges) et son port en tapis
#     manquent tous les deux ;
#   - PERSIL, CAROTTE, ÉGOPODE, dans « Ombellifères : ciguë mortelle ». Chez une apiacée
#     le fruit est l'ombelle SÈCHE, et c'est un caractère de détermination à part entière ;
#   - LAMIER, dans « Ortie / Lamier blanc » ;
#   - CONSOUDE, dans « Rosettes velues : digitale toxique » ET « Grandes feuilles en
#     rosette » — deux groupes d'un coup ;
#   - ACHILLÉE et PÂQUERETTE, dans « Astéracées à fleurs blanches » avec la camomille ;
#   - TANAISIE, dans « Astéracées amères » avec l'absinthe et l'estragon ;
#   - MENTHE et MÉLISSE, dans « Lamiacées odorantes ».
#
# ⚠ LE PIÈGE PRINCIPAL, et il est spécifique à ces deux aspects :
#   - LE PORT d'une herbacée, c'est la PLANTE ENTIÈRE EN PLACE : hauteur, silhouette,
#     façon de couvrir le sol. Un gros plan de feuille ou de fleur n'est pas un port,
#     même s'il est beau. C'est l'aspect le plus facile à mal taguer.
#   - LE FRUIT d'une aromatique (menthe, mélisse, marjolaine) est un akène minuscule que
#     personne ne photographie : ne pas s'acharner, le dire.
#   - LA POMME DE TERRE est le cas d'école : son fruit est une BAIE VERTE TOXIQUE que
#     presque personne ne connaît, et Commons est plein de TUBERCULES. Le tubercule est
#     une tige, pas un fruit. C'est exactement le genre d'erreur que ce dépôt existe pour
#     ne pas commettre.
#   - « Mentha sp. » est un GENRE : la catégorie Commons ramènera d'autres menthes.
#     Utiliser --categorie si besoin, comme pour le groseillier au lot 5.
# Puis relancer :
#   python3 scripts/verifier_atlas.py && python3 scripts/couverture.py
