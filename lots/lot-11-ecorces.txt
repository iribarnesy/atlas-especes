# Quatorze d'entre elles manquent AUSSI de rameau : viser les deux quand c'est possible.
#
# ⚠ CINQ DE CES ESPÈCES N'ONT PAS DE TRONC, et le lot sert aussi à le prouver.
# L'ajonc, le genêt, la ronce, le goji et le groseillier sont typés « arbuste » dans
# l'atlas, comme l'aubépine ou le noisetier — mais ce sont des ronces, des cannes ou des
# buissons de rameaux verts. Ils n'ont pas plus d'écorce qu'un sous-arbrisseau.
# Si la récolte revient vide pour eux, c'est un argument pour corriger leur TYPE dans
# l'atlas plutôt que de leur chercher indéfiniment un tronc : leurs manques sortiraient
# alors du compte, comme ceux des bruyères et de la vigne l'ont fait.
#
# ⚠ CE QU'IL FAUT VISER :
#   - le CHÊNE PÉDONCULÉ est le plus important du lot et le plus embarrassant à l'avoir
#     manqué deux fois : écorce épaisse, crevassée en côtes verticales régulières. Le seul
#     candidat trouvé jusqu'ici était une branche vue par-dessous à contre-jour ;
#   - le MICOCOULIER-like : figuier, mûrier et plaqueminier ont une écorce lisse ou
#     finement fissurée qu'on photographie peu — chercher dans la sous-catégorie (bark) ;
#   - l'IF : écorce rouge-brun qui se détache en plaques, très reconnaissable ;
#   - le GENÉVRIER : écorce grise se desquamant en longues lanières ;
#   - le PRUNELLIER et le TROÈNE : ce sont des arbustes, donc des TIGES plutôt qu'un tronc.
#     Une tige de prunellier est noirâtre — c'est l'origine du nom « épine noire ».
#
# ⚠ LES PIÈGES, ceux des lots précédents :
#   - préférer un sujet ADULTE, l'écorce jeune ne ressemble pas à l'écorce vieille ;
#   - refuser les branches à contre-jour et les photos de gemmage ou de blessure ;
#   - refuser les cultivars, nombreux chez le poirier et le plaqueminier.
# Puis relancer :
#   python3 scripts/verifier_atlas.py && python3 scripts/couverture.py
